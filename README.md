# Лингвистический верстак

Страница для лабораторных по курсу «ИКТ в лингвистике»: частотный список, конкорданс (KWIC), стилометрия. Работает в браузере телефона, без установки и без сервера.

## Как открыть

Дважды щёлкни `index.html`. Интернет не нужен.

## Что где лежит

```
index.html        разметка: поле для текста, вкладки, таблицы
css/styles.css    оформление (цвета — переменные в самом начале)
js/data.js        данные: VERSION, примеры текстов и слова для конкорданса, стоп-слова, клише
js/core.js        ядро: tokenize, freq, kwic, sentences, stylometry, wordLengths
js/ui.js          интерфейс: берёт данные из полей, зовёт ядро, рисует таблицы
tests/tests.html  проверки ядра — открыть после любой правки core.js
```

Файлы подключаются в порядке data → core → ui. Если поменять порядок, страница сломается.

## Правило правки

1. Новая лингвистическая функция → `js/core.js` (страницу не трогает).
2. Тест на неё → `tests/tests.js`, открыть `tests/tests.html`, всё зелёное.
3. Вывод на страницу → `js/ui.js`, разметка → `index.html`.
4. Поднять `VERSION` в `js/data.js`, коммит, тег.
